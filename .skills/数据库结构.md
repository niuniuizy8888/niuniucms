# 数据库结构

本文只保留表分组和变更规则，字段细节以 `core/install/install.sql` 为准。

## 1. 核心分组

- 内容：`vod`、`art`、`cate`、`tag`
- 用户与会话：`user`、`group`、`session`
- 配置与 KV：`kv`、运行时配置相关表
- 采集：批次、明细、绑定、来源相关表
- 插件：插件自有表按插件目录命名

## 2. 设计约定

- 主键、时间戳、状态位保持现有命名风格
- 大字段不要在列表查询里默认带出
- 计数、冗余字段由应用层维护，不依赖触发器

## 3. 新增字段或索引

- 先改 `core/install/install.sql`
- 再补存量库迁移说明
- 同步更新文档和更新记录
- 不用 `DROP + CREATE` 替代增量迁移

## 4. 插件表规则

- 插件表以插件名为前缀
- 新装路径和老库补建路径要分开写清楚
- 如果依赖索引，记得补老库迁移

## 5. 排障建议

- 先确认安装 SQL 与当前库结构是否一致
- 再确认是不是老库缺列、缺索引、或字段类型不匹配
- 结构问题优先用迁移修，不靠关闭严格模式兜底
