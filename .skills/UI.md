# UI 与模板说明

## 1. 前台模板

- 前台页面主要由 `route/` + `App\Service\Front` + `template/` 组成
- 模板变量默认不自动转义，输出前先确认边界
- 改模板后优先看真实渲染结果，不只看源码

## 2. 后台视图

- 后台页面主要由 `core/admin/route/` + `App\Service\Admin` + `core/admin/html/` 组成
- 卡片、表格、表单结构要保持闭合，避免版式错位
- 表格内表单尽量用表格外 `form` + `form="<id>"` 关联

## 3. 资源使用

- 静态资源优先使用站内文件
- 不新增公共 CDN 依赖
- 上传、图标、按钮、弹窗等 UI 改动，尽量复用现有样式体系

## 4. 常见问题

- 页面空白：先看 `runtime/log/`，再看编译产物
- 样式错位：先查容器闭合和表单嵌套
- 模板改了没生效：清对应缓存产物，再重载 PHP-FPM

## 5. 验证建议

- 前台至少验证首页、列表页、详情页或播放页中的一条链路
- 后台至少验证对应页面能正常渲染、提交、回显
- 涉及弹窗、表格、筛选条时，优先做一次浏览器实测
