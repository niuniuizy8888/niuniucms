# 读写分离使用说明

## 1. 目标

读写分离用于把读流量分到从库。默认关闭，按阶段开启。

## 2. 开启顺序

1. 先确认主从可用、只读账号可连通
2. 保持 `rw_split=false` 做基础冒烟
3. 开 `rw_shadow=true` 观察影子路由
4. 确认正常后，再开 `rw_split=true`

## 3. 配置原则

- 主配置仍以 `config.php` 为准
- 如使用 `database.php` 覆盖层，要把主库、从库、表前缀写完整
- 读写分离和缓存是两条独立链路，不要混着排查

## 4. 观察点

- 写后立刻读的页面是否稳定
- 影子日志或数据库侧读流量是否符合预期
- 从库延迟、连接数、错误日志是否异常

## 5. 回滚

- 直接把 `rw_split` 和 `rw_shadow` 关闭
- 必要时回退到单连接配置
- 回滚后优先验证后台写操作、采集和前台读取链路

## 6. 常见问题

- 改了开关没效果：先查是不是写错配置层
- 开分流后刚写的数据读不到：优先查粘滞时间和从库延迟
- 怀疑缓存问题时，不要先动数据库路由配置
