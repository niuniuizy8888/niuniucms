# 部署说明

## 1. 基本原则

- 站点根目录只放程序文件
- 运行时目录保留结构，不提交实际内容
- 部署说明只保留通用口径，不写宿主绝对路径

## 2. 发布前检查

- `core/config/config.php`、`core/config/database.php` 不入公共仓库
- `core/config/domain.php` 允许保留空模板
- 清空 `runtime/backup`、`runtime/cache`、`runtime/log`、`runtime/throttle` 的实际内容
- 确认安装锁、真实日志、临时包不随发布物带出

## 3. Web 层要求

- 保护内部目录和配置文件
- 正常放行前台、后台、接口入口
- 404、限流页、静态资源按现有入口与规则处理

## 4. 数据库与迁移

- 新装以 `core/install/install.sql` 为准
- 存量库结构变更走 `.skills/deploy/` 下的迁移脚本
- 迁移脚本保持幂等，不用 `DROP + CREATE`

## 5. 排障顺序

1. 先看 `runtime/log/`
2. 再看配置、权限、入口文件
3. 最后看缓存和编译产物
