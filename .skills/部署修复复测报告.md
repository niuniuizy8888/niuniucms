# 部署修复复测报告

日期：2026-10-29。基线：bcbbb0e。测试环境：PHP 8.5.12、MySQL 8.0、Nginx、Docker Compose。

## 修复和复测结论

- 凭据读取：预置旧版用户名及邮箱别名缓存后修改密码，大小写别名读取不再返回旧密码哈希；HTTP 旧密码被拒绝，新密码登录成功。
- 数据库故障：唯一键冲突触发 UPDATE 失败，返回 false；数据库和请求内用户密码保持原值。合法零行更新仍返回 0。
- 任务去重：超过 50 条历史任务后仍能识别活跃任务；八个并发进程入队仅生成一条活跃任务。
- 采集错误：取页失败后进入重试，第三次失败标记 failed；后续页失败同样抛错；合法空列表成功。成功处理器任务标记 finished。
- 独立消费：网页访问后 pending 任务保持原状态；独立 worker 实际消费任务并执行三次失败重试。
- Docker：默认 PHP 8.5 镜像构建成功，不依赖临时启动覆盖配置；Windows 检出换行不再阻断启动。
- 权限和安装：PHP 用户不可写核心文件、核心子目录及入口文件；只读核心权限下全新安装成功。
- 持久化：重建应用容器后 plugins、template、upload 中的临时标记全部保留，验证后已移除。
- 基础功能：安装、首页、静态资源、后台登录和管理页通过；安装后 install.php 返回 404，敏感路径返回 403。
- 回归检查：模板安全自测 80 项通过；237 个 PHP 文件语法检查通过。

临时账号、队列记录、测试标记及新装验收数据库已清理。测试脚本、凭据、日志、运行数据不随代码提交。
