伪静态设置

默认: ?video-1.html  |  伪静态1: video-1.html  |  伪静态2: video/1.html  |  伪静态3: video/1

nginx 伪静态规则：

# 伪静态1
location / {
    if (!-e $request_filename) {
        rewrite ^((.*)/)?(.*).html$ $1/index.php last;
    }
}

# 伪静态2/3
location / {
    if (!-e $request_filename) {
        rewrite ^((.*)/) /index.php last;
    }
}
