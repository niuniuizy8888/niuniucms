ES 安装说明
牛牛CMS 这套 ES 功能只用来做站内搜索加速。推荐先把 Elasticsearch 服务单独跑起来，确认可访问后，再回到本页填写连接信息。
一、推荐环境
  • Elasticsearch 7.x 或 8.x
  • 站点机能访问 ES 主机地址，例如 http://127.0.0.1:9200
  • 如果开启认证，准备好账号密码，或 API Key
二、Docker 快速启动示例

单机测试可先用下面这条命令启动：

docker run -d --name nncms-es \
  -p 9200:9200 -p 9300:9300 \
  -e "discovery.type=single-node" \
  -e "xpack.security.enabled=false" \
  -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" \
  elasticsearch:8.14.3
三、本页该怎么填
  • ES主机：例如 http://127.0.0.1:9200
  • ES索引：建议用站点专属索引名，例如 nncms_vod
  • ES用户名 / ES密码：开启账号认证时填写
  • API Key：如果你走 API Key，就填这里；和账号密码二选一即可
四、接入顺序
  1. 点「设置ES」保存主机、索引和认证信息
  2. 点「创建索引」初始化索引结构
  3. 点「批量写入」把现有视频标题灌入 ES
  4. 确认无误后，再把当前状态切到“开启”
五、常见排查
  • 主机不可达：先在服务器上确认 ES 端口能连通
  • 账号认证失败：检查用户名、密码或 API Key 是否正确
  • 创建索引失败：确认 ES 账号具备创建索引权限
  • 批量写入后搜不到：确认已经执行过「批量写入」，并且 ES 开关已开启
