地址替换

资源站换域名后在此执行：老域名 → 新域名。 本站立即替换（走与 api.php?route=replace 完全相同的执行器），成功后再上报商店登记， 勾选「立即推送」时商店会继续向**其它**站点推送。只需填域名（可带端口），不要带 http:// 或路径。
未取到资源站列表：请先在「视频采集」里导入商店资源站。
