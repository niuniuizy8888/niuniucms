全局限流

⚠️ 限流当前处于「开启」状态：可能影响异步采集——商店 rsync-task worker 会**逐页回调**本站 api.php?route=rsync（一次采集数百上千页）。若把窗口设得过小、或关掉了 api_token_exempt（令牌豁免），回调会拿到 HTTP 429，worker 重试 10 次后记 page fail，任务转为异常（error）（历史症状：page 31: http 429 | page fail）。 建议保持 api_token_exempt=开启，且 api_limit 不低于 30 / 600 秒。
限流当前「关闭」（出厂默认）：所有请求不做频率限制。开启前请先读下方红色提示—— 开限流有可能影响异步采集。
