安全提示：后台入口文件当前为 ， 默认可直接访问。该文件名众所周知，扫描器会主动探测；如需进一步隐藏后台入口，建议安装完成后手工改成随机文件名。
操作步骤：
  1. 把站点根目录的 admin.php 重命名为随机文件名，例如 3x9k2m.php。
  2. 打开 core/config/config.php，把 admin_entry 的值同步改为新的文件名，例如 'admin_entry' => '3x9k2m.php'。
请务必两步同时完成：
只改文件不改配置，或只改配置不改文件，后台链接和登录提交都会指向错误地址，导致后台 404 无法访问。
两步同步后，其余代码无需改动；后台链接会自动读取 admin_entry 生成。后续升级也会按该配置同步后台入口文件。
